For context on this one, check out my separate post on daegent. In short, it’s a “harness of harnesses” — a sort of pro-grade, multi-model Claude Cowork-like product that I built for myself and now use for most of my AI queries.

Of course, I want to interact with daegent on my phone. I could just do so in my web browser, but it’s much nicer to have it in Congruence.

In the previous Congruence post I discussed lockscreen widgets. Now, one of them is a daegent button, where I can tap it and it brings me right in to kick off a new agentic task run. I can select what harnesses and models I want and if it’s part of a project.

I can also now trigger a daegent run from the nearly-omnipresent notes bar — I just type in what I want and either hit “ADD” (to make a note) or “DAE” (to fire off daegent). “AI” just returns a quick answer instead of spinning up an agent.

Within the daegent module itself, I can see a list of all my tasks, including any that are currently running or chasing after certain goals.

Within the tasks, I can see the conversation, access specific messages via a table of contents, monitor ongoing goals, and send followups and continue the conversation.

And of course, there are push notifications for when tasks finish or need attention. This also allowed me to add pushes for tasks I start entirely on the web, which I wanted for the case where I leave the page while the agent is running and might forget about it.

With daegent in Congruence, I no longer go into the interface0, ChatGPT, or Claude apps!

This was a fun one — doubly-personalized software. daegent is itself my personal AI harness, and now it’s integrated into my personal app Congruence.
